Réglages et mise à jour

Compte Administrateur nécessaire pour cette fiche.

Une seule fois, à l’installation

☐ Réglages → Général → Fuseau horaire : Bruxelles (sinon les heures sont décalées) ☐ Réglages → Général : titre = nom de l’unité, slogan ☐ Réglages → Permaliens : « Titre de la publication », Enregistrer

Une nouvelle version du thème ?

1. Télécharge le zip sur github.com/guepe/les-scouts-unite (Releases). 2. Apparence → Thèmes → Ajouter → Téléverser un thème, choisis le zip, Installer, puis Remplacer l’actuel.
Toujours l’ancienne version ? Recharge (Cmd + Maj + R), puis vide le cache PHP chez l’hébergeur. Rien d’autre ne bouge : réunions, documents et réglages restent.
