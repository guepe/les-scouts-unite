Les documents de l’unité

Fiche médicale, autorisation parentale, droit à l’image, règlement : tu les mets une fois pour toute l’unité.

a

Documents → Ajouter, comme les animateurs (leur fiche 4).

b

Dans Pour qui ?, choisis Toute l’unité :

c

Le fichier, puis Publier.

Où ils apparaissent Sur chaque page de section, marqués « toute l’unité », et en tête de la page Documents. Seuls le staff d’unité et les administrateurs peuvent les modifier.
Nouvelle version ? Ouvre le document, choisis le nouveau fichier, Mettre à jour : il remplace l’ancien partout.
